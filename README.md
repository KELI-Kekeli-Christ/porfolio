# Portfolio - KELI Kekeli Christ

Portfolio professionnel moderne et interactif développé avec Next.js 14, TypeScript, Tailwind CSS et Framer Motion.

## 🚀 Technologies utilisées

- **Next.js 14** - Framework React avec App Router
- **TypeScript** - Typage statique
- **Tailwind CSS** - Framework CSS utilitaire
- **Framer Motion** - Animations fluides
- **Lucide React** - Icônes modernes

## 📋 Fonctionnalités

- ✨ Design moderne et professionnel
- 🎨 Animations fluides au scroll
- 📱 Responsive design (mobile, tablette, desktop)
- 🌙 Thème sombre optimisé
- ⚡ Performance optimisée avec Next.js
- 🎯 Navigation smooth scroll
- 📧 Section de contact interactive

## 🛠️ Installation

1. **Installer les dépendances**
   ```bash
   npm install
   ```

2. **Lancer le serveur de développement**
   ```bash
   npm run dev
   ```

3. **Ouvrir dans le navigateur**
   ```
   http://localhost:3000
   ```

## 📦 Build de production

```bash
npm run build
npm start
```

## 🎨 Personnalisation

### Modifier les informations personnelles

Les informations sont directement intégrées dans les composants. Modifiez les fichiers suivants :

- `components/Hero.tsx` - Informations principales
- `components/About.tsx` - Section à propos
- `components/Skills.tsx` - Compétences techniques
- `components/Experience.tsx` - Expériences professionnelles
- `components/Projects.tsx` - Projets
- `components/Certifications.tsx` - Certifications
- `components/Contact.tsx` - Coordonnées de contact

### Modifier les couleurs

Les couleurs peuvent être modifiées dans `tailwind.config.ts` dans la section `colors.primary`.

## 🚀 Déploiement

- Assurez-vous de mettre à jour les liens GitHub et LinkedIn dans les composants
