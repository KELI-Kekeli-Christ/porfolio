Portafolio Next.js (el nombre del repositorio tiene una sola “r”). Tema oscuro, animación al desplazar y sección de contacto.

```bash
npm install
npm run dev
```

Producción: `npm run build` y luego `npm start`. El sitio es `http://localhost:3000`.
